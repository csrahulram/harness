# What the harness remembers about each person

One folder per account. Both notes are plain markdown you can read and edit; the harness reads them
into every prompt, so keep them short — each is capped at 400 tokens and the cap simply truncates.

- **`profile.md`** — durable facts worth knowing every time: names, preferences, what you are
  working on.
- **`soul.md`** — how to relate to you: tone, how much detail you want, what you have corrected
  before.

Today you write both by hand. From M2 the harness proposes additions itself, and everything it
writes records when it learned it and from which session, so you can judge and delete it.

A folder here is removed when its account is deleted.
